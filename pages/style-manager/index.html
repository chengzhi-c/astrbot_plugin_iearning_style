入乡随俗 · 使用说明

让机器人从聊天中学习并模仿他人的说话方式。

三层表征

  • 通用：稳定的说话基调（语气/用词），全部注入每次回复，上限 10 条。
  • 情境：场景→行为的固定反应，按 FIFO 容量管理，最新 20% 为缓冲位。
  • 特定：群内梗与释义，含触发正则（trigger_regex），命中才注入。

常用操作

  • 编辑后点击对应层的 保存本层 才生效；未变化条目会保留学习统计。
  • 立即学习 等价于聊天命令「学习总结」；清空本会话 等价于「清空风格」。
  • 未保存修改时顶部横幅可「保存全部」或「丢弃」；切换会话/刷新会二次确认。

快捷键

  • / 聚焦会话搜索
  • Ctrl + S / ⌘ + S 保存当前层
  • Esc 关闭弹窗 / 帮助 / 抽屉

数据与隐私

  • 所有数据来自插件本地存储，页面经 AstrBot 面板桥接读取，不会上传第三方。
  • 特定层正则受 ReDoS 防护约束（长度 ≤200、拒绝嵌套量词，并限制运行时匹配时长）。
